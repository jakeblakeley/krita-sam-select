SAM Select

Object selection powered by Meta's Segment Anything 3, running locally on Apple Silicon with MLX.

Using the tool

Pick SAM Select in the toolbox (next to the selection tools) or press W.

  • Click an object to select it. With “Highlight object under cursor” on, the object is previewed before you click.
  • Drag a box to select every object inside it (or just the main object; see Tool Options).
  • Type what to select in the box at the bottom of the canvas (“type what to select”), for example cat, red car or windows, and press Return. Every match is selected.

Combining selections

Modifiers work exactly like Krita's selection tools, and hold for clicks, drags and Return in the text box:

  • ⇧ Shift: add
  • ⌥ Option: subtract
  • ⇧⌥: intersect
  • ⌘ Command: replace
  • ⌘⌥: symmetric difference

With Switch Control/Alt Selection Modifiers enabled in Krita's preferences, ⌘ and ⌥ swap roles, as they do for the built-in tools. The default mode is shared with Krita's other selection tools, and Space+drag, pinch and scroll keep navigating the canvas.

First run

Choose Install SAM 3… in Tool Options. It installs a private Python environment (~350 MB) in ~/Library/Application Support/SamSelect, then downloads the 1.7 GB model once. Everything runs offline after that.
